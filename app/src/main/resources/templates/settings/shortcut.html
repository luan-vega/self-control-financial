2. Automação no app Atalhos

  1. Abra Atalhos → Automação → Nova Automação → Transação (Carteira) e escolha os cartões.
  2. Marque Executar Imediatamente.
  3. Adicione a ação Obter Conteúdo do URL com a URL abaixo, método POST.
  4. Em Cabeçalhos, adicione Authorization com o valor Bearer + espaço + seu token.
  5. Em Corpo da Solicitação, escolha JSON e adicione os campos: amount = Valor, description = Comerciante, type = EXPENSE.

Exemplo do corpo

{
  "date": "2026-10-26",
  "description": "Padaria",
  "amount": "12,50",
  "type": "EXPENSE",
  "category_id": "opcional"
}

Sem date, vale o dia de hoje. Sem category_id, usamos a categoria do último lançamento com a mesma descrição.
